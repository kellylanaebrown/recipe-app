# **App Name**: RecipeSnap

## Core Features:

- Image Upload: Allow users to upload images of dishes or ingredients.
- Ingredient Identification: Use AI to identify ingredients in the image and propose multiple matches for ambiguous components. Use a tool to ask for confirmation when components are uncertain.
- Recipe Generation: Generate recipes based on the identified ingredients. Provide different variations if possible.
- Recipe Display: Display the generated recipe with ingredients, instructions, and a photo (if available).
- Save Recipes: Allow users to save generated recipes to their personal collection.
- Search recipes: Allow users to search previously created recipes using keywords

## Style Guidelines:

- Primary color: Warm, earthy orange (#E07A5F) to evoke a sense of comfort and home cooking.
- Background color: Light beige (#F2E8CF), a desaturated tone that evokes organic paper and a natural, foodie sensibility.
- Accent color: A muted teal (#3D405B) to provide a cool contrast, analogous to orange on the color wheel.
- Headline font: 'Playfair', serif, elegant feel, great for titles. Body font: 'PT Sans', sans-serif, good for reading.
- Use minimalist, line-based icons for ingredients and actions.
- Clean, card-based layout for displaying recipes and ingredients.
- Subtle transitions and animations when loading recipes or identifying ingredients.
